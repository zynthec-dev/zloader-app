# Working on zLoader

zLoader is independently maintained by zynthec-dev. Use a development branch and
follow [AGENTS.md](AGENTS.md) and the build instructions in [README.md](README.md).
Keep transport/signing changes separate from visual branding where practical.
Preserve original copyright notices and open-source licenses.

Run the App Group, transport and Core Data confinement harnesses, then build the
host, backup, widget and tunnel. Describe physical-device limits separately from
compiler and archive validation. Never include pairing files, Apple credentials,
profiles, certificates, private keys, anisette state or device identifiers.

These changes are not submissions to SideStore. Anyone choosing to submit a
future SideStore contribution must consult the original project's participation
policy and communicate with its maintainers directly.
