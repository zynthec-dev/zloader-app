# Profile-authorized optional capabilities — 0.7.40

The Apple Account installation/signing pipeline omits ungranted application capabilities, including HealthKit, clinical records, background delivery, push, Siri, associated domains and increased/extended memory rights. Previously simultaneous HealthKit and memory omissions prevented the memory fallback and rejected the entire profile. The corresponding features are unavailable in the signed app; Apple profiles are never modified to grant rights. Granted rights remain in the signature.

The same reduction is applied when considering installed/local/portal profile reuse, so a compatible existing profile need not be regenerated. Reuse still requires the selected team, exact bundle ID, certificate, valid expiry and all selected devices. Network Extension rights required by embedded VPN providers and the shared container required for zLoader itself remain protected: these components cannot function without their authorization. Other ungranted app capabilities are removed from the signature. Wildcard profiles are reusable when their bundle prefix and all other requirements match. Each component uses its own profile and omission set; the saved IPA records omissions in ZLoaderOmittedOptionalEntitlements. Imported signing identities remain strict and can use the entitlement editor to remove unsupported rights explicitly.
